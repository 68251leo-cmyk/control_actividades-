# Preguntas parte 2 
## 1. Flujo colaborativo 
1.Fork: primero se le hace un fork para poder tener el respositorio en nuestra cuenta de github y porder trabajar ahi

2.-clone: se clona el respositorio en nuestra maquina de manera local para poder trabajar

3.-branch: se crea un nueva rama para implementar las modificaciones sin afectar el de produccion

4.-Modificacion de archivos: Se modifican archivos o se crean nuevos

5.-git add: se agregan a la area de staging los archivos que se registraran para el siguiente commit

6.- git commit: se crea un registro de las modificaciones y se agregan al repositorio local

7.-git push: se mandan las modificaciones del repositorio local al remoto que esta en github

8.-review: se ven las modificaciones que se hicieron y si no hace conflicto 

9.-merge: une dos ramas con las modificaciones

10.- pull requests: se manda una peticion al dueño del proyecto original sobre las modificaciones en el cual se hace un merge tambien
